# 📖 Инструкция для системного администратора
## Сайт-визитка ГБУК ГАПП «Казачья Воля» (flat-file, без базы данных)

---

## 🚀 Развёртывание — всего 3 шага

### Шаг 1. Скачайте архив
Скачайте архив сайта (`kazakvolya.zip`) и распакуйте его на своём компьютере.

### Шаг 2. Распакуйте в папку сайта
Загрузите **содержимое** папки на веб-сервер, например в `/var/www/html/`
(или в любую подпапку домена). Должно получиться так:

```
/var/www/html/
├── index.php          ← главная страница
├── admin.php          ← панель управления
├── config.php         ← настройки (пароль админа)
├── data/              ← весь контент в JSON-файлах
├── includes/          ← служебные файлы
└── theme/             ← оформление (css, js, картинки)
```

Никаких composer, npm, баз данных и миграций **не нужно**.
Требования: PHP 8.0+ и обычный Apache/Nginx с PHP-FPM «как есть».

Проверка: откройте `http://ваш-сайт.ру/` — должен открыться сайт.

### Шаг 3. Зайдите на site.ru/admin.php
Откройте в браузере **`https://ваш-сайт.ру/admin.php`** и войдите:

| Логин  | Пароль по умолчанию |
|--------|---------------------|
| `admin`| `KazakVolga2026!`   |

## 🔑 Как сменить пароль администратора (задание №1 после установки!)

1. Откройте в браузере `https://ваш-сайт.ру/newpass.php`
2. Введите новый пароль (минимум 8 символов) → «Сгенерировать».
3. Скопируйте готовую строку вида `'pass_hash' => '$2y$12$...'`
   и вставьте её в файл `config.php` вместо старой (там есть подсказка-комментарий).
4. Сохраните `config.php` и **удалите файл `newpass.php` с сервера**.

## ✏️ Что можно менять через админку (`/admin.php`)

- **📰 Новости** — добавлять, редактировать, удалять новости.
  Чтобы добавить фото: загрузите картинку в `theme/img/` по FTP/панели хостинга
  и укажите путь к ней в поле «Картинка», например `theme/img/koncerty.jpg`.
- **🎭 Афиша** — ближайшие концерты + ссылка на билеты (kassir.ru).
- **⚙️ Настройки** — адрес, телефоны, e-mail, часы работы, ссылки.

Тексты страниц («О коллективе», «Репертуар») лежат в файле `data/pages.json` —
его можно править в любом текстовом редакторе (главное — не сломать кавычки и запятые).

## 🛠 Частые проблемы

| Проблема | Решение |
|----------|---------|
| Белый экран / ошибка 500 | Проверьте, что на сервере PHP 8.0+. Обычно помогает вернуть права: `chmod -R 755 /var/www/html` и `chown -R www-data:www-data /var/www/html/data` |
| «Не удалось записать файл» в админке | У веб-сервера нет прав на запись в папку `data/`. Выдайте: `chmod 775 data && chown www-data:www-data data` |
| Забыли пароль | Выполните шаги из раздела «Как сменить пароль», либо замените `pass_hash` в `config.php` на значение из нового `newpass.php` (разверните копию файла локально и сгенерируйте) |
| Шрифты не загрузились | Это нормально: сайт автоматически использует системные шрифты Georgia/Arial |

## 📁 Структура файлов (справочно)

```
config.php                 настройки и хэш пароля админа
index.php                  фронтенд (роутер: ?page=...)
admin.php                  мини-CMS (вход по паролю)
newpass.php                генератор хэша пароля (УДАЛИТЬ после настройки!)
includes/helpers.php       общие функции (чтение/запись JSON)
includes/afisha.php        страница «Афиша»
includes/news.php          страница «Новости»
data/settings.json         контакты и общие данные
data/pages.json            страницы: Главная, О коллективе, Репертуар, Контакты
data/news.json             новости
data/afisha.json           мероприятия
theme/default/*.php        шаблоны (header, footer, страницы)
theme/css/style.min.css    все стили (один файл)
theme/js/script.min.js     меню + ленивая загрузка
theme/img/*.svg            заглушки картинок (замените на реальные фото)
```
